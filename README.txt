M&K SOUND — мультиссылка

Содержимое:
index.html — страница
mk-sound-logo.webp — фирменный логотип (основной формат)
mk-sound-logo.png — резервный формат для совместимости

Ссылки Instagram, Telegram, PromoDJ уже работают.
Для YouTube: открой index.html в текстовом редакторе, найди блок <a class="link" aria-disabled="true" и замени его на обычную ссылку, указав href="АДРЕС_КАНАЛА", target="_blank" и rel="noopener noreferrer". Можно также прислать адрес канала ChatGPT для обновления.

Публикация бесплатно: загрузить index.html, mk-sound-logo.webp и mk-sound-logo.png в корень репозитория, открыть Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save. После зелёного статуса открыть https://djm1shka6-pixel.github.io/mk-sound/ и обновить страницу сочетанием Ctrl+F5.
После публикации сайт доступен по адресу username.github.io/repository/.
